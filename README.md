# BrainMaze: Brain Electrophysiology, Behavior and Dynamics Analysis Toolbox - Data Files

This toolbox provides data conversion tools for the BrainMaze project.

## Installation

```bash
pip install --force git+https://github.com/bnelair/brainmaze_datutils.git@dev
```
